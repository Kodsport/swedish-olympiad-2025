\problemname{Trollkarlen Theodor}

\noindent

Det finns $N$ monster, där det $i$:te
monstret har $h_i$ antal liv. Theodor vill döda alla monstren, 
och för att göra detta kan han avfyra magiska explosioner. 
Han siktar på ett särskilt monster och gör $S$ skada på det (så att monstret förlorar $S$ liv). 
Explosionen gör sedan $A$ skada på alla monster (alltså att alla monster förlorar $A$ liv). 
Vad är minsta antalet rundor som krävs för att han ska kunna vinna?

\section*{Indata}
Den första raden innehåller tre tal, $N$ ($1 \leq N \leq 10$), $S$ ($1 \leq S \leq 10^9$) och $A$ ($0 \leq A \leq 10^9$), vilket är de motsvarande tre talen som nämns ovan.
Den andra raden innehåller $N$ tal $h_1, h_2, \ldots, h_N$ ($1 \leq h_i \leq 10^9$) som beskriver antalet liv som vardera monster har.

\section*{Utdata}
Skriv ut minsta antalet rundor som krävs för att döda alla monster.


\section*{Poängsättning}
